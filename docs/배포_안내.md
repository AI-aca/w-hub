# W-HUB 배포 안내 (1단계 뼈대)

원장님 결정(2026-11-20): **기존 Supabase 프로젝트(School Record)에 새 영역만 추가**, GitHub는 새 저장소 `AI-aca/w-hub`, 구글 로그인은 기존 클라이언트 ID를 설정 변경 없이 사용.

기존 표·함수·Secrets·Auth 설정·저장소는 **바꾸지 않습니다.** 새로 생기는 것은 아래뿐입니다.

| 새로 생기는 것 | 위치 |
|---|---|
| 스키마 `core`, 역할 `core_app` | School Record DB |
| Edge Function `platform` | School Record 함수 목록 |
| 저장소 `AI-aca/w-hub` + Pages | GitHub |

## 1. DB (SQL Editor)

1. `supabase/migrations/0001_core.sql` 실행(두 번 실행해도 안전).
2. 운영 설정 넣기(공개 저장소에 적지 않는 값):
   ```sql
   update core.settings set value = '["원장 구글 계정1","원장 구글 계정2"]'::jsonb, updated_at = now() where key = 'owner_emails';
   update core.settings set value = '"<구글 클라이언트 ID>"'::jsonb, updated_at = now() where key = 'google_client_id';
   ```
   - `allowed_origins` 기본값은 `["https://ai-aca.github.io"]`.
   - 설정은 함수가 1분마다 다시 읽습니다.

## 2. 서버 함수 `platform`

- 폴더 `supabase/functions/platform` 전체(index.ts, handler.ts, deno.json, lib/, actions/)를 함수 이름 `platform`으로 배포.
- **Verify JWT: 켬**(화면이 공개용 publishable key를 보냄).
- **프로젝트 Secrets는 추가하지 않습니다.** 함수는 자동 제공 값 `SUPABASE_DB_URL`만 씁니다.

## 3. GitHub 저장소 `AI-aca/w-hub`

1. 코드 올리기(이 폴더 전체, `.github/workflows/ci-deploy.yml` 포함).
2. Settings → Pages → Source: **GitHub Actions**.
3. Settings → Secrets and variables → Actions → **Variables**:
   - `WHUB_API_URL` = `https://xphtctpbysbbdyjaxidh.supabase.co/functions/v1/platform`
   - `WHUB_SUPABASE_PUBLISHABLE_KEY` = School Record의 publishable key(공개용, 기존 사이트들도 쓰는 값)
4. main에 올리면 검사(타입·서버 시험·화면 시험) 통과 후 자동 배포 → https://ai-aca.github.io/w-hub/

## 4. 배포 후 확인

- 원장 계정으로 구글 로그인 → 두 작업공간·관리 메뉴 확인.
- 관리 → 센터 목록 확인·수정.
- 다른 계정 로그인 → 승인 대기 → 원장이 승인·권한 지정 → 해당 작업공간만 보이는지 확인.
