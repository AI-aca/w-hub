## 할 일 (순서대로)
1. **계산 파일 하나**: 점수 범위·요약(응시·평균·만점·90점 이상·최고/최저)·회차 순서·학교별/학생별 추이·우수자 대상·이름 가림·교육과정·단원 태그·난이도 단계·출제 통계·리포트 수치(C-01~C-04·C-08·C-10·C-14~C-21·C-23)를 서버·화면이 같이 쓰는 순수 함수로 만든다. **원본 함수를 그대로 떼어 무작위 자료와 비교하는 시험(차이 0)을 먼저** 만든다(문서 47 방식, 53번 §3 의 실행을 시작점으로). 평균 표시는 Q-07 결정대로 한 가지로.
2. **DB(추가만)**: ① `exam_analysis`(과목·선택 목록·시험·문항·직전 저장본) ② `org.centers.display_name` ③ 4단계 `assess` 에 내신용 칸 추가(53번 §7). 기존 표·칸은 건드리지 않는다. 모든 변경은 두 번 실행해도 안전하게, 작업 전 백업, 되돌릴 수 있게.
3. **서버 기능**(권한은 Q-03 결정대로): 분석 — 시험 목록·열기·저장(저장 표시 충돌 검사·직전 저장본·단원 태그·200문항)·직전 저장본 되돌리기·삭제(관리)·출제 통계·엑셀 읽기 결과 반영·가져오기(관리)·존칭·오타 분석(서버에서만 키 사용). 성적 — 시험(센터×학기×시험×과목) 열기·칸 단위 저장(동시 수정 보호·점수 0~100·상태·이름 번호 규칙)·삭제·되돌리기·변경 기록·함께 보는 중·변경 번호·통계용 원자료. **새 검사**: 모든 기능에서 센터 범위·영역 권한을 서버가 확인(53번 F-03·F-07·F-08), 입력자 = 로그인 계정(D-02), 학교 이름 변경·삭제가 성적 연결을 끊지 않게 `school_id` 로 연결(F-06). `feature-map.json` 의 actions 와 내신 항목 status 를 고친다.
4. **화면**: 분석 메뉴 — 사이드바(학년도·과목·학교급·학교·학년·시험) · 문항 입력(엑셀 업로드·업로드 전으로 되돌리기·저장 표시 알림·직전 저장본·임시 저장본·존칭·오타 창) · 문항 리포트(이미지·PDF 흰/검) · 출제 통계(이미지) · 시험 목록 · 설정(과목·선택 목록·가져오기). 성적 메뉴 › 내신 — 성적 입력(학교별 묶음 행·고등 열·이름 후보=학생 명부·자동 저장·충돌 창·함께 보는 중·저장 중 창 닫기 경고) · 통계 · 학교별 추이 · 학생별 추이 · 우수자 이미지(흰/검 2장, 이름 가림) · 변경 기록. 공통 부품(입력표·확인 창·이미지 저장·사이드바)은 4단계/3-2A 것을 재사용(X-02·X-07). 성적 입력의 '입력자 이름' 창은 만들지 않는다(D-02). 사용법 안내를 새 화면 기준으로 쓴다(D-15).
5. **옮겨 오기**: `tools/migrate/jobs/naesin_papers.ts`(센터·학교·과목·선택 목록·시험 336·문항 8,545·직전 저장본 24) · `naesin_results.ts`(시험 44·성적 3,676·학생 1,109 키). 읽기 전용, 서버끼리, 다시 돌려도 같은 결과, `legacy_id` 로 재실행 안전. 학생 연결은 53번 §7·Q-08(애매한 것은 `merge_queue`). 개인정보(이름)는 로그·문서에 남기지 않는다.
6. **연결(5-D)**: 같은 학교·학년·학기·시험·과목의 성적 화면 '이 시험 문항 리포트'와 분석 화면 '우리 학생 점수 분포'(X-11), 학생 화면 내신 점수(X-04·X-08).
7. 기능 지도 갱신·인수인계 README '지금 상태' 갱신.
