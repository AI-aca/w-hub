1. **원장님 결정**(51번 문서 §11) 중 개발을 막는 것: Q-01(주말반 모의 연결) · Q-02(센터) · Q-03(권한) · Q-04(동명이인) · Q-06(저장 기록) · Q-09(형성평가) · Q-10(커트라인 그룹). 나머지는 권장값으로 시작해도 되고 결과를 보고한다.
2. **3-2 C 가 main 에 합쳐진 뒤** 시작(커트라인·1지망·모의 종합 추이가 같은 점수를 쓰므로). 합쳐진 최종 구조로 51번 문서 §9(X-04·X-05)를 한 번 더 대조한다.
3. 원본 새로 받기: GitHub `AI-aca/wmock` 최신본(대조표 기준 HEAD `ca6513d`, 이후 변경 있으면 `index.html` 해시 대조 후 대조표 갱신), 운영 사이트와 같은지 확인.
4. 마이그레이션 번호·서버 함수 번들 기록은 **총괄이 배정**한다(이 카드에서 정하지 않음).

## 할 일 (순서대로)
1. **계산 파일 하나**: 원본 `calc`·`cutPct`·`avgList`·학년 석차·표시 규칙(C-01~C-19)을 서버·화면이 같이 쓰는 순수 함수로 만든다. 원본 함수를 그대로 떼어 무작위 자료와 비교하는 시험(차이 0)을 **먼저** 만든다(문서 47 방식).
2. **DB(추가만)**: `assess` 스키마 새로 만들기(51번 §7) + 회차 연결 칸. 기존 표·칸은 건드리지 않는다.
3. **서버 기능**: 시험 목록·열기·만들기·설정 저장(과목별 충돌 검사)·칸 단위 저장(동시 수정 보호, 만점 초과·음수 거부)·삭제(관리)·되돌리기·함께 보는 중·변경 번호·엑셀 가져오기·성적표 계산 묶음. 권한은 성적·모의고사 영역(Q-03 결정대로). `feature-map.json` 의 actions·모의고사 항목 status 고침.
4. **화면(성적 메뉴 › 모의고사)**: 사이드바(학년도·시험 목록) · 시험 설정 · 성적 입력 · 종합성적 · 순위별 정리 · 성적표 출력(2쪽·인쇄·PDF·ZIP) · 학생별 성적 추이 · 시험 목록·가져오기. 성적표 평균 규칙(C-15)·붙여넣기·자동 반영·저장 중 창 닫기 경고 포함. 사용자 승인·로그 탭은 만들지 않는다(기존 관리 화면).
5. **옮겨 오기**: `tools/migrate/jobs/mock_exams.ts`(시험 9개·학생 줄 1,016·점수 칸 57,591). 읽기 전용, 다시 돌려도 같은 결과, 학생 연결 규칙은 51번 §7. 개인정보(이름)는 로그·문서에 남기지 않는다.
6. **주말반과 공유(X-01~X-03, X-05)**: Q-01 결정대로 연결된 모의 회차의 점수·만점을 `assess` 에서 읽게 한다. 옛 칸(`class.mock_max`, `class.records.mock`)은 서버 함수 배포 **뒤에** 정리하고, 그 전에는 둘 다 동작해야 한다.
7. **커트라인 공유(X-04)**: 입력 한 곳(모의고사 시험 설정)으로 하고 3-2 C 의 1지망 판단이 그 값을 읽게 한다(Q-10 결정대로).
8. 사용법 안내(새 화면 기준)·기능 지도 갱신·인수인계 README '지금 상태' 갱신.

## 필요한 DB 변경 개요 (migration 번호: **총괄이 배정**)
- 새 스키마 `assess`(계획서 4-4): `assessments`(kind='mock', 학년도·차수·제목·시행일·`config`{환산 비율, 메모, 영역 순서}·`class_session_id`·`legacy_ref`) · `sections`(수학·과학) · `items`(번호·영역·만점) · `attempts`(학생·센터·그 시점 학년·`ver`) · `item_scores`(값 있는 칸만, `ver`) · `cutoffs`(줄 이름·수학 환산·과학 환산·총점) · 변경 기록(`attempt_log`, Q-06 결정에 따라).
- 권한·RLS: 기존 표와 같은 방식(서버 역할만 읽기·쓰기, 화면용 역할은 접근 불가).
- `people.student_aliases` 에 source `mock`(이미 허용됨) 별칭만 추가.
- (Q-02 결정에 따라) `org.centers` 센터 추가.
- 3-2 C 의 `class.cutlines`·주말반 `class.mock_max`·`class.records.mock` 정리는 **서버 함수 배포 뒤 별도 단계**(추가 먼저, 지우기 나중).
- 모든 변경은 두 번 실행해도 안전하게, 작업 전 백업, 되돌릴 수 있게.

## 검증 (끝났다고 말하기 전)
- `npm run check` 지적 그대로 따름 → `npm run verify`(타입·구조·서버·화면 시험 + 캡처) → 캡처를 직접 열어 확인.
- 51번 문서 §12: 계산 차이 0, 옛 9개 시험 학생 수·문항 수·점수 칸 수·점수 합·학생별 지문 대조, 성적표 숫자(학생 20명 이상) 옛 사이트와 대조, 동시 입력 시험.
- 원장님께는 캡처와 쉬운 말 요약: 바뀐 것 · 확인한 것 · **확인 못 한 것**.

## 완료 조건
- 옛 모의고사 사이트의 63개 예정 기능이 W-HUB 에서 모두 되거나, 51번 문서에 '일부러 다름/만들지 않음'과 이유가 적혀 있고 원장님이 확인함.
- 성적표 숫자가 옛 사이트와 같음(INV-04). 하나라도 다르면 전환하지 않음.
- 전환일은 원장님이 정한다(약속 3). 전환일에 2028학년도 시험을 마지막으로 한 번 더 복사하고, 그날부터 옛 사이트는 보기만.
