## 4. 화면별 대조

권한 표기: **관리**=원본 admin, **입력**=원본 member(로그인한 승인 계정). W-HUB 로는 이미 `mock_users` 작업이 admin→성적·모의고사 *관리*, member→*입력*(editor)으로 옮겼다. **원본에서 member 가 할 수 있는 일이 매우 넓다**(시험 만들기·설정·가져오기·되돌리기까지) — 서버가 막는 것은 사용자 3·시험 삭제·로그 5개뿐(§6).

### 4-1. 로그인 (L266~L275, L474~L497)
- 누가: 누구나 → 구글 로그인 → 승인된 계정만 세션. 처음 보는 계정은 '승인 대기'로 명단에 올림(서버 L177~L193).
- W-HUB: 이미 있음(1단계). 이 화면은 만들지 않는다. 승인 요청 흐름(4건)은 W-HUB 의 기존 계정 관리가 대신함.

### 4-2. 사이드바 — 학년도·시험(차수) 목록 (L278~L287, L516~L547)
- 학년도 선택: 시험이 있는 학년도 + **2027~올해+1** 모두 표시, `○○학년도 (총 N회)`. 처음 열 때: 마지막으로 연 시험(브라우저 기억) 또는 가장 큰 학년도.
- 시험 카드: `N차 · 응시 n명 · 시험 이름`. 응시 n = 이름이 있는 학생 수. 학생별 성적 추이 탭에서는 목록이 꺼지고 "학년도 전체 차수를 함께 봅니다" 안내.
- 로고 = 첫 화면(시험 닫기). 이동 전 '저장하지 않은 변경'·'자동 저장 안 된 칸' 확인(`leaveOk`).
- W-HUB: 성적 메뉴 사이드바(계획서 8-1)의 `종류 · 학년도 · 센터 · 시험 목록` 공통 틀. 시험 목록 표기 "6차 · 132명"은 계획서 그대로.

### 4-3. 시험 설정 탭 (L1091~L1206)
- 누가: 입력(누구나). 단위: 시험 한 개. **'시험 설정 저장'을 눌러야 반영**(성적 입력은 칸마다 자동 저장). Ctrl+S 도 같음.
- 기본 정보: 학년도(2000~2100) · 차수(1~99) · 시험 이름(100자) · 수학/과학 환산 비율 · 메모(2000자). 학년도·차수를 바꾸면 같은 학년도·차수의 다른 시험이 있을 때 서버가 거부(서버 L399~L400). 성적표 제목 미리보기 `[ ○○학년도 영재학교 대비 ] 시험이름 [N차] 결과표`.
- 환산 비율로 만점 계산: 지금 문항 기준 수학·과학·총 환산 만점을 보여 줌(저장 안 함). 배점이 없으면 경고.
- 학교별 합격 커트라인(환산 점수): 줄(구분 이름·수학 환산·과학 환산, 총점은 자동 합) 최대 20줄(서버 L78). **새 시험 기본 3줄** `서울, 경기, KSA` / `인천, 대구, 대전` / `광주, 세종`(L327). 줄 이름이 비면 서버가 줄을 버림. 시험 7(2028학년도 1차)은 `인천, 대구, 대전, 세종` / `광주` 로 **줄 구성이 다름**.
- 영역 이름: 수학·과학 각각 쉼표로 구분(최대 10개, 순서대로 성적표에 표시). 기본 수학 `기하, 조합, 대수` · 과학 `물리, 화학, 생명과학, 지구과학`. 영역을 바꾸면 문항의 영역 선택 목록이 바뀜.
- 문항 표: 문항번호 · 영역 · 배점(0.5 단위 입력, 숫자 입력칸) · 삭제 ✕. +1/+5/+10문항. 최대 200문항/과목(서버 L62). 문항을 지우면 그 문항 점수도 같이 지워짐(점수가 있으면 확인창).
- 특별한 경우: 문항을 늘리거나 줄인 **그 과목에** 다른 사람이 먼저 입력했으면 저장 거부("다른 사람이 그사이 수학 문항이나 점수를 바꿨습니다") — 과목별 변경 번호(`revs.math/sci`)로 판단(서버 L404~L405). 과목 설정이 안 바뀌었으면 거부하지 않음.
- 새 시험 만들기 창(L837~L865): 학년도·차수(다음 번호 자동)·시험 이름 입력. 앞 차수가 있으면 "문항 구성·영역·배점 복사" 체크(복사하면 시행일 비움·커트라인 값 비움·**환산 비율은 복사**). 같은 학년도·차수가 있으면 거부.
- W-HUB: 성적 › 모의고사 › 시험 설정 탭. 3-2A 의 '평가 설정 모의 만점'과 역할이 겹침(§9).

### 4-4. 성적 입력 탭 (L904~L1087, 서버 `cellSet`)
- 누가: 입력(누구나). 단위: **학생 한 줄 × 문항 한 칸**. 칸을 떠나면(또는 1.2초 뒤) 바뀐 칸만 서버로 보냄. 서버는 그 순간 최신 내용에 그 칸만 반영 → **여러 명이 동시에 입력해도 서로 지우지 않음**(서버 L329~L389).
- 보기: [수학만]·[과학만]·[전체] (브라우저에 기억, 기본 수학만). 열: NO · 이름 · 센터 · 학년 · 문항들 · 자동 계산(영역 점수·수학 계·과학 계·총계). 머리글 4줄: 문항번호 / 영역(첫 글자) / 만점 / 평균.
- 이름: 공백은 입력하는 즉시 제거. 센터: 공백 제거 + 끝의 "센터" 자동 제거(`센터`만 쓰면 그대로) + 안내. 학년: 초6·중1·중2·중3·빈칸(선택하면 바로 저장).
- **동명이인**: 같은 시험 안에서 **이름이 같으면** 저장 거부(서버 L349~L353, 센터가 달라도 거부). 이름 뒤에 숫자를 붙이도록 안내(`홍길동1`). 같은 이름은 파란색 표시. → 옛 자료의 `이름+숫자` 5줄은 W-HUB 의 `name_no` 와 연결해야 함(Q-04).
- 빈 이름 줄은 저장하지 않음(맨 아래에 항상 빈 줄 하나 유지, 줄 추가 +1/+5/+10). 이름을 지우면 "그 학생과 수학·과학 점수가 지워집니다" 확인 후 삭제. 이름 없이 점수만 치면 "이름을 먼저 입력해야 점수가 저장됩니다".
- **0점은 반드시 0, 미응시는 빈칸**(화면 안내 ①). 빈칸 = '없음'(평균·순위에서 빠짐), 0 = 점수 0(평균에 들어감).
- 엑셀 붙여넣기: 탭 구분 여러 줄을 현재 칸부터 **보이는 열 순서대로** 채움(이름·센터 칸에서 시작하면 그 줄들의 이름도 만듦). 만점 초과·숫자 아님은 그 칸만 비우고 목록 안내. 이름이 겹치는 줄은 저장하지 않고 안내.
- 키보드: Enter·↓ 아래 칸, ↑ 위 칸, 칸 끝에서 →·칸 처음에서 ← 이동. 선택한 줄·문항 열 강조.
- 상태 표시: `✓ 자동 저장됨` / `저장 중…` / `⚠ 저장 실패 · 다시 시도`(누르면 재시도, 연결 오류면 5초 뒤 자동 재시도). 서버가 거절하면(동명이인·만점 초과) 안내 후 최신 내용으로 다시 불러옴.
- 함께 보는 중: 15초마다 서버에 알려 같은 시험을 보는 다른 사람 이름을 표시(서버 `ping`). 5초마다 변경 번호를 확인해 **다른 사람이 입력한 내용을 자동 반영**(내가 입력 중인 칸·저장 전 칸은 덮지 않음, L653~L695).
- 창 닫기·이동 시: 저장 전 칸이 있으면 경고(`beforeunload` L581).
- W-HUB: 성적 입력 공통 입력표(계획서 8-1 "붙여넣기·만점 초과 차단·자동 저장·동시 수정 보호"). 3-2A 의 '엑셀 붙여넣기'(이름 점수 → 이름으로)·'저장 중 창 닫기 경고'·'만점 넘으면 저장 거부'가 같은 성격. 동시 수정 보호는 ver 칸으로 이미 사용 중.

### 4-5. 종합성적 탭 (L1252~L1310)
- 누가: 입력(누구나, 보기만). 단위: 시험 전체. 위: 백분위 구간별 환산 점수 평균(C-11). 아래: 학생 × (영역·수학 계·과학 계·총점·환산 점수) 각각 **점수·석차·백분위**. 센터 선택(번호는 다시 매김, 석차는 전체 기준 — C-22). [수학 ▸]·[과학 ▸] 머리글로 영역 접기/펼치기, [전체 접기/펼치기]. 머리글 고정(`stickHead`). [엑셀로 저장]: `○○학년도 N차 종합성적(_센터).xlsx`, 시트 `종합성적`, 점수는 소수 1자리 숫자·백분위는 `12.3%` 글자.
- 특별한 경우: 점수 없는 칸은 석차·백분위가 "미응시". 이름 있는 학생이 없으면 "입력된 학생이 없습니다".

### 4-6. 순위별 정리 탭 (L1313~L1359)
- 기준 선택: 수학 석차 · 과학 석차 · 총점(종합) 석차 · 환산 석차. 센터 · 학년(전체/초6/중1/중2/중3/학년 미입력) 필터. 미응시(기준 점수 없음)는 제외. 정렬: 기준 순위 → 같으면 이름 가나다. 머리글(점수·순위·백분위) 누르면 그 기준 정렬, 다시 누르면 반대, [기준 순위]로 원래 순서. 열: 기준 순위 · 학년 석차(툴팁 `중1 N명 중`) · 이름 · 센터 · 학년 · 수학/과학/총점/환산 × (점수·순위·백분위). [엑셀로 저장] 파일명에 기준·센터·학년 포함.

### 4-7. 성적표 출력 탭 (L1551~L1784)
- 누가: 입력(누구나). 단위: 학생 1명 = **A4 2쪽**. 상단: 이름 검색(전체 센터) · 센터 · 학년 · 학생 목록(가나다) · ◀ ▶ (센터 안에서 이동, 처음·끝이면 안내).
- 1쪽: 학생명·센터 / 환산 총점 / 환산 백분위 / 종합 점수 → 성취도 점수 표(영역별·과목 계·종합: 만점·평균줄·개인·백분위) → 환산 점수 표 + 학교별 합격 커트라인 표(점수·백분위) → 성취도 그래프(수학 환산·과학 환산·환산 총점 막대: 만점·평균들·개인). 문구: "최근 5개년 2단계 지필 통과 실적 기준의 '합격 안전선'… 최종 합격을 보장하지 않습니다"(L1619, 11-16 개정).
- 2쪽: 수학·과학 **문항별 점수**(문항·영역·만점·평균줄들·개인). 미응시 과목은 "미응시", 응시했는데 칸이 빈 문항은 "-".
- 로고(`WZ_LOGO`)·글꼴(Pretendard) 포함. 제목: `[ ○○학년도 영재학교 대비 ] 시험이름 N차 결과표`.
- [인쇄]: 브라우저 인쇄(A4, 여백 0). [PDF로 저장]: 쪽마다 화면 캡처 → jsPDF → 파일 `시험이름 [N차] 결과표 [센터] 이름.pdf`. [일괄 PDF (ZIP)]: **고른 센터·학년의 학생 전원** PDF 를 ZIP 으로(같은 파일 이름이면 `(2)`…). 확인창에 평균 설정·'저장하지 않은 변경도 반영' 안내.
- W-HUB: 계획서 8-1 "성적표(공통 출력: 모의 2쪽 양식)". 외부 라이브러리 4개(html-to-image · jspdf · jszip · chart.js)를 CDN 에서 받아 씀 — W-HUB 는 CDN 사용 정책 확인 필요(Q-12).

### 4-8. 학생별 성적 추이 탭 (L1481~L1549)
- 누가: 입력(누구나). 단위: **학년도 전체**(시험 고르지 않음) × 학생. 이름 검색 · 센터 · 학생 · ◀ ▶. 표 + 그래프 12개(환산·총점·수학·과학 × 점수·석차·백분위). 다른 사람이 새로 입력하면 오른쪽 아래에 "다른 분이 새로 입력한 점수가 있습니다 [새로 고침]"(자동으로 다시 그리지 않음).
- W-HUB: 계획서 8-1 '추이(학생별·학교별)'. 학교별 추이는 내신 쪽(원본 모의에는 없음).

### 4-9. 시험 목록·가져오기 탭 (L1858~L1971)
- 시험 목록: 학년도·차수·시험 이름·응시·수정 시각·수정자(이메일 앞부분)·[열기]·**[삭제](관리)**. 삭제는 직전 내용을 `exam_backups` 에 남긴 뒤 지움(서버 L479~L493).
- 저장 기록(오른쪽 카드): 지금 열어 둔 시험의 **수학/과학 각각 최근 10개** — 저장 시각·저장한 사람·입력 인원·학생 수·[이 시점으로 되돌리기]. 되돌리기 전에 확인창에 '되돌리기'를 직접 입력해야 함(`typeConfirm`). 그 과목만 바뀌고 다른 과목은 그대로, 지금 내용도 기록에 남아 다시 되돌릴 수 있음. 기록 규칙(서버 L105~L117): **같은 사람이 10분 안에 계속 입력하면 하나로 묶음**, 사람이 바뀌거나 10분이 지나면 '바로 전 상태'가 하나 추가, 과목별 10개 넘으면 오래된 것 삭제, 시험 설정·가져오기·되돌리기 직전에는 무조건 하나 남김.
- 기존 구글 시트(성적입력 툴) 가져오기(**화면에서만 관리 전용, 서버는 막지 않음**): xlsx 여러 개 → 탭 `[N차] 성적입력`·`[N차] 성적표 출력`을 읽어 학년도·차수·문항·배점·학생·커트라인을 자동 인식(`parseTool` L1927). 미리보기 표(새로 추가/덮어쓰기) → [가져오기 실행] → 같은 학년도·차수가 있으면 내용을 바꿈(직전 내용은 백업). 만점 초과는 만점으로 맞춰 가져옴. 구글 시트 탭이 `postMessage` 로 파일을 보내는 통로(L1963)도 있음(docs.google.com 출처만) — **계획서 결정: 받지 않음**(옛 2027학년도 자료는 이미 `mock.exams` 에 들어 있음).
- W-HUB: 시험 목록은 사이드바와 같은 장치. 가져오기는 '엑셀 가져오기' 공통 단추(계획서 8-1). 구글 시트 통로는 만들지 않음. 저장 기록 방식은 Q-06.

### 4-10. 사용자 승인 및 로그기록 탭 (L1787~L1854)

## 8. 새 시험(2028학년도)과 주말반 모의고사 회차의 관계 — 원본에서 확인된 점

- 원본 wmock 시험에는 **주말반 회차와 이어지는 칸이 없다**(시행일 `date` 도 비어 있음). 시험 제목에만 "11.07", "11.21" 이 글자로 있음.
- 주말반(참고사이트) 쪽은 회차를 '모의'로 표시하고 과목별 원점수 한 칸씩 받는다(3-2A). 모의 종합 200점은 `1.2×수학% + 0.8×과학%`(수학:과학 60:40, 평가 설정). 이것은 **wmock 환산 점수(수학 계×1.2 + 과학 계×2/3)와 수학 만점 100 · 과학 만점 120 일 때만 같은 값**이다(2028학년도 1·2차 해당, 3차 형성평가는 과학 만점 100 이라 다름).
- 계획서 Q-05 확정: 주말반 모의고사 = 모의고사 2028학년도 차수. → 연결 칸이 필요(계획서 4-4 `class_session_id`).

## 12. 검증 계획 (화면 시험·계산 대조)

1. 계산: 원본 `calc`(L417~L470)·`cutPct`·`avgList`·학년 석차를 **그대로 떼어** 무작위 자료(영역 수·문항 수·미응시·소수·동점·한 과목만 응시·학년 섞임·10명 미만 학년)로 W-HUB 계산과 비교 — 차이 0. 환산 비율 `1.2`·`2/3` 외에도 `0.5` 등 임의 값.
2. 실제 자료: 옛 9개 시험을 옮긴 뒤, 시험마다 학생 수·문항 수·점수 칸 수·점수 합, 학생별 점수 배열 지문, **성적표(영역·환산·백분위·커트라인) 숫자**를 옛 사이트와 W-HUB 에서 같은 학생 20명 이상으로 비교(INV-04).
3. 동시 입력: 두 사람이 같은 시험의 다른 칸을 동시에 입력해도 서로 안 지우는지, 같은 칸 충돌 시 보호되는지.
4. 화면: 시험 만들기→설정→입력(붙여넣기·만점 초과)→종합성적→순위→성적표(인쇄·PDF·ZIP)→추이 시나리오 + 캡처. 성적표 PDF 는 원본과 쪽·줄 넘침이 같은지 눈으로 확인.
5. 가져오기: 구글 시트 엑셀 2~3개(`[N차] 성적입력`·`성적표 출력` 탭)로 미리보기·덮어쓰기.

## 13. 확인하지 못한 것

- W-HUB 실서버의 센터 명부(`org.centers`) 현재 목록·`people.students` 행 수: 조회하지 않음(이 작업은 옛 DB 읽기만).
- 3-2C(dev-32c)의 최종 구조: 미커밋 작업물만 읽음. 커트라인·그룹·회차 연결은 바뀔 수 있음.
- 참고사이트(Firebase)에 저장된 커트라인 값과 wmock 커트라인 값이 같은 출처·같은 숫자인지: 참고사이트 쪽 값을 읽을 수 없어 대조 못 함.
- 성적표 PDF 가 실제로 만들어지는 모양(글꼴·그래프 위치): 브라우저에서 실행해 보지 않음. 코드와 스타일만 확인.
- 옛 서버 함수의 **배포 시각·이전 판**: 배포본만 읽음. 로컬 PC 의 `영재학교 모의고사 관리` 폴더 사본은 쓰지 않음(AGENTS 규칙).
- DB 역할 `mock_app` 의 권한·RLS 설정: 조회하지 않음(옛 DB 는 읽기 전용 유지).
- 선생님 22명 중 실제로 시험 설정·가져오기를 쓰는 사람: 로그(시험저장 299건 중 설정·가져오기 구분)는 `detail` 글자로만 구분되어 집계하지 않음.
- 사용 중인 브라우저·기기별 성적표 인쇄 결과.
