### 10-3. W-HUB 규칙 (이미 정해진 것, 계획서 11장·0003)

- W-HUB DB 는 `whub_app` 역할만 접근(정책 `whub_app_all`), anon·authenticated 는 `revoke all`. 접근 검사는 서버 함수가 세션→작업공간→영역 단계→센터 범위→대상 순서로 한다. 입시 표들도 같은 틀을 따른다.
- 학생 링크는 `people.student_access` 의 해시 토큰(만료일·마지막 사용 시각). 학생이 쓸 수 있는 동작은 서버가 **목록으로 제한**한다(자기 자소서·메모·답변·최종 제출만).

### 11-3. 옛 링크 자동 이동

학생에게 이미 나간 링크는 `…/2027SCI/?student=<학생 링크>` 이다(School-Record 는 학생용 링크 없음, 교사 도구).

| 번호 | 선택지 | 설명 | 추천 |
|---|---|---|---|
| D-20 | A. 옛 사이트를 전환일에 **이동 안내 화면으로 교체** | 2027SCI 저장소의 `index.html` 을 '새 주소로 이동' 화면(+자동 이동)으로 바꾼다. 이 저장소는 INV-01('고치지 않는다')의 예외가 되므로 **원장님 승인 필요**. GitHub Pages 는 서버 이동(301)이 안 되어 자바스크립트·meta 이동만 가능 | 가장 단순. 전환일 이후만 적용 |
| | B. 옛 링크 값을 **새 토큰의 일부로 그대로 사용** | W-HUB 가 `student_aliases(source='sci')` 에 옛 링크를 기억해 두고 새 주소가 `?student=<옛 링크>` 형태도 받아 준다(해시 저장). 이동 화면(A)이 링크 값을 그대로 넘겨 주면 **학생이 새 링크를 따로 받지 않아도 됨** | A 와 함께 |
| | C. 새 링크를 모두 새로 발급해 문자로 재안내 | 옛 링크는 전환일에 닫음 | 입시철 중이면 학생 혼란 큼 |

- 어떤 방식이든 **전환일·옛 사이트 접근 중단 시점은 원장님이 정한다**(약속 3, INV-05). 입시철 학생 화면은 전환일 전에 W-HUB 에서 미리 써 보고(시험 복사본) 확인한다.
- 옛 링크의 안전: 링크는 임의 12자리이며 비밀번호가 없다. 새 방식에서는 링크 노출 시 **재발급·만료**가 가능해진다(옛 링크는 이 기능이 없음). 옛 링크를 새 토큰으로 이어 갈지(B) 새로 발급할지(C)는 이 위험과 학생 불편의 균형이다.

## 12. 확인 못 한 것

- School-Record **PC 폴더 사본과 배포본의 차이**(배포본만 읽음). `_작업중` 파일은 보지 않음.
- 2027SCI 의 **실제 사용 흐름**(학생이 링크로 열고 저장·체크리스트·예상질문 연습을 하는 화면)을 실사이트에서 직접 눌러 보지 않았다. 코드로만 확인. 특히 학생 체크리스트가 11-23 보안 변경 뒤에 동작하는지는 미확인(AI 결과 행이 08-26 이후 0건이라는 사실만 확인).
- `deletePersonalStatementSnapshot` 이 화면 어디에서 불리는지(2027SCI script.js 에서 호출 위치를 찾지 못함 — 미확인).
- 두 원본의 학생이 **같은 사람 구성인지**(학년·학교 비교 안 함). 이름 해시 겹침 0명만 확인.
- `student_records`(1개)·`school_materials`(4개) 버킷이 과학고에서 쓰이는지.
- School-Record 서버의 합격 사례 추출·분류 상세(`exemplarExtract`)와 `exPerson` 이름 규칙은 동작 이름·흐름만 읽고 단계별 입출력 대조표는 만들지 않음(다음 단계에서 세부 대조).
- 진단지 화면(viewResult)의 **모든 문구·막대·색**을 항목별로 대조하지 않음(구조만). W-HUB 판은 같은 학생의 옛 진단지와 새 진단지를 나란히 열어 사람 눈으로 대조한다.
- 옛 서류의 **실제 화면 캡처**는 없음(원본은 읽기 전용 코드 확인만).
- `getSettings` 가 `school_questions`(표 없음)를 읽는 경로가 실제로 쓰이는지(설정 `schools` 가 있어 쓰이지 않을 것으로 보임).
- 2027SCI 서버(DB) 쪽 정책(표·저장소)은 **문구만 읽고 실제 요청으로 시험하지 않음**(학생이 자기 행의 칸을 고칠 수 있는지, 공개 키로 저장소 목록·삭제가 되는지는 운영 DB 쓰기 위험이 있어 시도하지 않음).
- School-Record 서버 코드 줄 번호는 '정리한 사본' 기준(공개 저장소에는 없음).
