## 바뀐 기능 (두 사이트 같음)
1. **자기소개서 탭 '선생님 수정' 열** (script.js `TABLE_COLUMNS.ps` 맨 끝 열 `psTeacherEdit`, backend_logic.js `getAllPsProgress`)
   - 어느 화면: 자기소개서 목록 표(학생 한 줄에 한 칸), 맨 오른쪽(관리 열 뒤).
   - 누가 보나: 선생님(교사)·관리자. 학생 화면에서는 열을 걸러 냄(학생도 데이터는 같이 읽지만 표시 안 함).
   - 무엇 단위: 학생 한 명당 '선생님이 자소서를 저장한 횟수'. 표시 `수정 N회`, 없으면 `-`.
   - 계산: `personal_statements` 전체 행(페이지 1000건씩)을 읽어 `writer='선생님'` 인 행의 `updated_at` 을 학생별로 시간순 정렬, **앞 행과 10초 넘게 떨어져야 1회 추가**(한 번 [저장하기]로 여러 문항이 저장되면 서버 시각이 조금씩 달라서). 결과는 전역 `window.PS_TEACHER_EDIT_MAP[student_link]={count}`.
   - 특별한 경우: 문항·버전(version_label)·학년도 구분 없이 학생 전체 합산, 화면의 학년도 필터와 무관하게 읽음. 선생님이 한 번도 저장 안 했거나 writer 가 비어 있는 옛 행은 0회(`-`). 10초 안에 선생님이 두 번 저장하면 1회로 셈(알려진 한계). 이 횟수는 '저장 행 시각' 기준이라 같은 문항을 다시 저장해도 이력 행이 새로 생기는 한 셈에 들어감(이력 행 삭제 시 줄어듦 — 이력 삭제 동작은 미확인).
   - 쓰는 DB 칸: **쓰기 없음.** 읽기만: `personal_statements.student_link, question_no, content, updated_at, version_label, writer`. `writer` 는 48번에서 이미 추가된 칸(선생님 저장 = '선생님', 그 외 '학생').
2. **자소서 편집창 글자수 표시 맨 위로** (annot.js 스타일 1줄 `#modal-ps-editor .char-counter{z-index:3}`): 색칠 첨삭 층이 글자수 표시를 가리던 문제 수정. 기능 변화 없음.
3. 열 글씨 크기를 다른 칸과 같게(`1d077ac`/`be70ef3`): 표시 크기 조정만(48번 이후 순 변경에는 글자 크기 지정이 따로 안 보임 — 두 커밋 합산 결과 기준).
