## 권한 — 원장님이 Claude 에게 위임("알아서 지금부터 권한줘"), 2026-11-24 적용
- 영역 설명: 수업 = 열람(보기)/입력(고치기·반 배정)/관리(과정·학기·과목·반 설정). 성적·주말반 = 열람/입력(성적 넣기)/관리(평가 설정).
- **적용함:** 주말반 강사 6명(강사 명단에 이메일 연결된 활성 강사 전원, 모두 1차 학기 수업 담당)에게 **성적·주말반 = 입력**. 기존 모의고사 권한은 그대로 유지(1명 관리, 5명 입력). 적용 후 계정 목록으로 6명 모두 확인, 성적·주말반 권한 보유자는 정확히 6명.
  - 선생님 화면: 수업 메뉴 안에 '성적 입력·입력 현황'만 보임. 시간표는 입력표 고르기 안에서 읽기만. 처음 열면 본인 담당 칸(강사 이메일 일치) 중 오늘 이전 가장 최근 수업.
- **아직 안 줌(의도):** 수업 영역(시간표·진도·업무 일정·반편성). 선생님들이 지금 2028win 에서 고치고 있어 두 곳에서 고치면 자료가 갈라짐 → 전환일에 2028win 최신 자료 다시 복사 후 부여, 그날부터 2028win 은 보기만.
- 평가 설정(관리)은 원장님만.
- 모의고사만 있는 나머지 16명은 그대로(주말반 강사 아님).
