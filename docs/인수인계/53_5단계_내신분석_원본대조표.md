## 12. 검증 계획 (개발 때)

1. **계산 차이 0**: C-01~C-04·C-08·C-10·C-14~C-16·C-18·C-21(가림)·C-23 을 원본 함수에서 떼어 무작위 자료(문서 47 방식 — 묶음당 수백 값)로 W-HUB 계산 파일과 대조. 이 문서 §3 의 실행이 그 첫 확인.
2. **옛 자료 복사 대조**: 시험 336·문항 8,545(칸별 채움 수·시험별 칸 내용 sha256·문항 수) · 직전 저장본 24 · 성적 3,676줄(점수 있는 줄 3,463·점수 합계·소수 304·상태 분포·시험 44개별 응시 인원·학생 1,109 키별 줄 수) · 학교 140·과목 18·선택 목록 204. 센터별·학년도별 합계 일치. 다시 돌려도 같은 결과.
3. **리포트 대조**: 무작위 시험 20개의 문항 리포트 수치(총 문항·상위 난이도 비율·출제 단원 수·도넛 값·형태 분포)와 출제 통계(조건 조합 20개)를 옛 사이트 화면과 같은 값인지 확인.
4. **명예의 전당 대조**: 같은 시험·기준(90/만점)으로 대상 인원·묶음·정렬 순서·가려진 이름이 옛 화면과 같은지(이미지 비교 + 명단 비교, 실명은 문서에 남기지 않음).
5. **통계·추이**: 학교별 평균 추이 8곳·센터 전체·학생별 추이(직전 대비·같은 학교·학년 평균)를 학생 20명 이상 대조.
6. **권한·센터 범위**: 다른 센터 자료 접근 거부, 관리 전용 10개 기능 거부(서버 시험), 우수자 실명 열람 권한.
7. **동시 입력**: 두 사람이 같은 시험·같은 줄·같은 칸을 동시에 바꾸기(충돌 창), 문항 시험 동시 저장(저장 표시 충돌), 저장 중 창 닫기 경고, 5초 반영·함께 보는 중.
8. **이미지·PDF**: 흰/검은 배경·파일 이름·표 줄 사이 쪽 나눔·글꼴 포함(오프라인에서도 같은 글꼴).
9. `npm run check` → `npm run verify`(타입·구조·서버·화면 시험 + 캡처) → 캡처를 직접 열어 확인. 원장님께는 캡처와 쉬운 말 요약: 바뀐 것 · 확인한 것 · **확인 못 한 것**.

## 13. 확인하지 못한 것

- 옛 사이트를 **브라우저로 실제 조작해 보는 시험**(버튼 동작·캡처)은 하지 않음 — 이 문서는 화면 코드와 서버 코드를 전부 읽고 계산 함수를 떼어 실행한 결과. 개발 때 옛 사이트 화면과 숫자를 나란히 대조해야 함.
- **Gemini 호출이 실제로 되는지**·모델 이름 유효성(로그인이 필요해 시험 안 함).
- W-HUB 운영 DB 의 현재 상태(센터·학교 표의 행 수, 강사 명부와 담당자 글자의 일치, 계정 목록) — 운영 DB 조회는 이번 지시 범위 밖이라 안 함. 4단계 `assess` 스키마의 최종 모양도 아직 main 에 없어 §7 은 초안.
