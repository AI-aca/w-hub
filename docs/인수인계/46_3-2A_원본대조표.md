# 46. 3단계 2차 A — 참고사이트 원본 코드 대조표 (2026-11-24)

계기: 모의고사 만점을 '선생님이 입력표마다 넣기'로 잘못 만든 것을 원장님이 지적. 원인 = 화면·칸만 옮기고 값의 출처(어느 화면·누가·무엇 단위)를 원본 코드까지 따라가지 않음.
방법: 참고사이트 app.js 에서 입력·평가 관련 값마다 정의 위치를 따라가 W-HUB 와 대조.
앞으로: 3-2 B 부터는 이 표를 먼저 만든 뒤 코드를 짠다.

| 값/기능 | 참고사이트(원본) | W-HUB 처음(3-2 A) | 결과 |
|---|---|---|---|
| 입력 단위 | 반 × 과목(수학은 담당 1·2) × 회차 | 시간표 상세 칸(회차 × 반, 과목·강사 1명) | 같음(2028win 시간표가 담당별로 칸이 나뉨) |
| 출결 빈칸 | 빈칸 = 출석(기본값). '빈 칸은 기본값(출석·교재 지참·지적 0·미흡 0·발표 0)으로 계산' | 빈칸 '—' + '모두 출석' 단추 | **고침**: 빈칸 = 출석, 단추 없앰 |
| 교재 미지참 | 체크 | 체크 | 같음 |
| 태도 지적·노트 미흡·발표 | 횟수, 상한 없음 | 횟수 0~50 | 일부러 다름(잘못 친 큰 수 막기) |

| 만점 넘는 값 | 조용히 만점으로 깎음 | 저장 거부 + 알림 | 일부러 다름(잘못 친 값이 몰래 바뀌지 않게) |
| 엑셀에서 붙여넣기 | 있음(점수 열만 → 가나다 순, '이름 점수' → 이름으로) | **없었음** | **추가**. 이름이 없거나 동명이인이면 전부 취소(원본은 순서로 넣어 버림) |

## 함께 들어간 것
- 강사 소속 센터(원장님 요청): 관리 › 센터·학교·강사 › 강사 편집에 '소속 센터'(같은 작업공간 센터만, 하나).

## 배포
- DB 0006 두 번에 나눠 적용(새 표·칸 먼저 → 서버 함수 → 옛 칸 지우기), 실서버 자료 수 그대로(회차 50·칸 144·성적 0).
- 서버 함수: 옛 판에서 바뀐 부분만 25곳 고쳐 넣고, 결과가 새 번들과 sha256 같음을 확인 후 배포(fae4b360…).
- 화면: PC 폴더에 바뀐 15개 + 저장 문구, 다시 받아 대조 일치 → 원장님 bat 대기.
