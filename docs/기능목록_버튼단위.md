> 공통 버튼(닫기·취소·확인·저장 등)은 빠짐. 화면 제목 중 `…` 가 섞인 것은 코드가 채우는 제목(예: 학생 이름)이다. 2028win 은 화면이 대부분 코드로 그려져 버튼 수가 적게 잡힘 → 3단계(수업) 때 화면을 직접 열어 보강.

## A. 지난번(11-20 폴더 기준) 분석과 달라진 점
1. **생기부 진단:** 배포된 서버에서 `recordFileUrl`(원본 PDF 열기)에 관리자 검사가 **없음** → 강사도 열 수 있음. 문서 11과 일치, 폴더 사본이 옛 버전이었음(F-SR1 해결).
2. **과학고·외고:** 비밀번호를 더 이상 화면으로 내려보내지 않음. DB 함수 `login_check`·`admin_check`·`admin_update_secrets`·`get_gemini_key` 로 서버에서 확인, 비밀값은 `app_secrets` 표(공개 접근 막힘)로 분리(11-23).
3. **과학고:** DB가 YONSEIIE 프로젝트의 `science` 칸으로 이동, 파일 저장소 `sci_student_records`·`sci_school_materials`. 학생 표에 `admission_year`(입시 연도) 추가.
4. **외고:** 학년도 필터(기본값 올해+1), 공통과제 답변이 학년도별(`common_assignments_answers.admission_year`), 학교별 문항 표 `school_questions`.
5. **모의고사(11-16):** 성적표 출력에 학년 선택 추가, 필터 이름 통일. **내신(11-16):** 학생 성적 색을 문항 분석과 통일, 우수자 이미지 하단 센터명.
6. **2028win:** Supabase 라이브러리 제거, 모든 읽기·쓰기를 서버 함수 `weiz2028`(login·checkPass·logout·load·upsert·delete)로.
7. **연세 온라인 진단:** 8월 이후 변경 없음. 여전히 GAS + 구글 시트·드라이브.

## B. 보안 확인 (지금 운영 중, 원장님 판단 필요 — W-HUB로 옮기면 해결됨)

- 파일 저장소 4개 모두 공개(public) + 공개 삭제 규칙 있음.
- 비밀번호·Gemini 키(`app_secrets`)는 막혀 있음(11-23 조치 확인).
- 당장 막으면 두 사이트가 멈춤(브라우저가 직접 읽고 쓰는 구조). 대안: W-HUB 입시 단계(6·7단계)를 앞당기거나, 그 전까지 매일 백업.
